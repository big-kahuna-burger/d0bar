What you will see, and what you will not

      

        

          Tier
          On a real page
        

        

          1 — requests, vitals
          
            Full. Read from the browser's own entries, so third-party traffic shows up too.
          
        

        

          2 — service worker
          
            Off, and the panel says so. A worker cannot be registered from
            another origin. Requests will show as untraced. This is the degraded path working
            correctly, not a failure.
          
        

        

          4 — OpenTelemetry
          Live only if the page already runs an OTel web SDK. Most do not.
        

      


      
When it will not load at all

      
    
        
  • 
          Content-Security-Policy. Most large sites block a script from an
          origin they did not list. Nothing appears and the console says why. Try a smaller
          site, or your own app in development.
        
    • 
        
  • 
          HTTPS pages. A page on https: will not load a script
          over http:. Use this against a local or http: page.
        
    • 
        
  • 
          Server not running. This page is served by it, so if you are reading
          this it is up.
        
    •
